== Accessibility Conformance Report (VPAT)

An Accessibility Conformance Report (ACR) records how a product measures against a set of accessibility standards. {companyname} publishes these reports using the https://www.itic.org/policy/accessibility/vpat[Information Technology Industry Council (ITI) Voluntary Product Accessibility Template (VPAT)].

The current report is listed first. Earlier reports are retained so that organizations running an earlier release can reference the report that applies to the version they have deployed.

[[reporting-an-accessibility-issue]]
== Reporting an accessibility issue

To report an accessibility issue in {productname}, or to request an accommodation, contact {companyname} through the https://support.tiny.cloud/hc/en-us[{companyname} support portal].

Include the following information where it is available:

* The version of {productname} in use.
* The browser, operating system, and assistive technology, including version numbers.
* The steps required to reproduce the issue.
* The expected behavior and the observed behavior.

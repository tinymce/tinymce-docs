[[editing-experience]]
== Editing experience

[cols="1,1"]
|===

a|
[.lead]
xref:use-tinymce-inline.adoc[Inline editing]

Edits content in place on the page, with the toolbar shown only when the content has focus.

a|
[.lead]
xref:use-tinymce-distraction-free.adoc[Distraction-free editing]

Edits content inline without a menu bar or toolbar, using keyboard shortcuts and contextual toolbars.

a|
[.lead]
xref:editor-important-options.adoc#placeholder[Placeholder text]

Shows hint text in an empty editor.

a|
[.lead]
xref:toolbar-configuration-options.adoc#toolbar_mode[Toolbar modes]

Controls how toolbar buttons that do not fit are shown: in a floating panel, a sliding drawer, a scrolling row, or wrapped onto more rows.

a|
[.lead]
xref:contextmenu.adoc[Context menus]

Shows a menu of relevant actions when a user right-clicks content.

a|
[.lead]
xref:contexttoolbar.adoc[Context toolbars]

Shows a small toolbar next to selected content, such as an image or a link.

a|
[.lead]
xref:keyboard-shortcuts.adoc[Keyboard shortcuts]

Lists the built-in keyboard shortcuts and explains how to add custom shortcuts.

a|
[.lead]
xref:editor-skin.adoc[Skins]

Changes the look of the editor interface, including a dark skin.

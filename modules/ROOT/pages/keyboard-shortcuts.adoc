|Paste as plain text |Ctrl+Shift+V |⌘+Shift+V |xref:introduction-to-powerpaste.adoc[powerpaste]
|===

[NOTE]
====
The `+tinycomments+` plugin uses *Ctrl+Alt+M* (or *⌘+⌥+M*) for two different actions. When the editor has focus, the shortcut adds a comment or opens and focuses a reply. When the comments sidebar has focus, the same shortcut shows or hides the sidebar.
====

[NOTE]
====
The `+powerpaste+` shortcut performs the same action as the core *Ctrl+Shift+V* (or *⌘+Shift+V*) shortcut listed in xref:#editor-keyboard-shortcuts[Editor keyboard shortcuts]. The plugin provides it for browsers that do not support switching paste modes with the *Shift* key.
====

IMPORTANT: The `+ai+` and `+tinymceai+` plugins both use *Ctrl+J* (or *⌘+J*). The `+ai+` plugin declares `+tinymceai+` as incompatible, so when both are included in the `+plugins+` option the `+ai+` plugin does not load and its shortcut is not registered.

[[accessibility-keyboard-shortcuts]]
== Accessibility keyboard shortcuts

This is a list of available keyboard shortcuts within the editor user interface. The shortcuts that move focus into the editor user interface from the content area, such as *Alt+F9* (or *⌥+F9*), are listed in xref:#editor-keyboard-shortcuts[Editor keyboard shortcuts].

[cols=",,",options="header"]
|===
|Action |Windows or Linux |macOS
|Execute command |Enter / Spacebar |Enter / Spacebar
|Focus on next UI Element(such as: Menu bar, Toolbar, Toolbar Group, Status Bar Item) |Tab |Tab
|Focus on previous UI Element(such as: Menu bar, Toolbar, Toolbar Group, Status Bar Item) |Shift+Tab |Shift+Tab
|Focus next control on a toolbar or the menu bar |Right Arrow / Down Arrow |Right Arrow / Down Arrow
|Focus previous control on a toolbar or the menu bar |Left Arrow / Up Arrow |Left Arrow / Up Arrow
|Focus next item in an open menu |Down Arrow |Down Arrow
|Focus previous item in an open menu |Up Arrow |Up Arrow
|Open menu or toolbar menu button |Down Arrow / Spacebar / Enter |Down Arrow / Spacebar / Enter
|Open group toolbar button |Spacebar / Enter |Spacebar / Enter
|Open the menu on a split toolbar button, when the arrow section has focus |Down Arrow |Down Arrow
|Open the popup menu on split toolbar buttons |Shift+Enter |Shift+Enter
|Open submenu |Right Arrow |Right Arrow
|Close submenu |Left Arrow / Esc |Left Arrow / Esc
|Close dialog |Esc |Esc
|Close menu |Esc |Esc
|Close notification |Esc |Esc
|Move focus back to editor body |Esc |Esc
|Execute a command in a multiline dialog text field |Ctrl+Enter |Ctrl+Enter
|Switch to another dialog tab, when the tab menu has focus |Arrow keys |Arrow keys
|Resize the editor, when the resize handle has focus |Arrow keys |Arrow keys
|===

In a dialog, the *Tab* and *Shift+Tab* keys cycle through the dialog controls and do not move focus out of the dialog. The *Enter* key submits the dialog, except in a multiline text field.

NOTE: Browsers and Screen Readers provide additional shortcuts within the editor context.

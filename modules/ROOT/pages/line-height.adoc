= Line height
:navtitle: Line height
:description: Line height sets the spacing between lines of text in paragraphs, headings, list items, and table cells.
:description_short: Set the spacing between lines of text.
:keywords: line height, line spacing, leading, lineheight, line_height_formats

include::partial$misc/core-feature-summaries.adoc[tag=line-height]
Authors can increase the spacing of dense text to make it easier to read, or reduce the spacing to fit more text into a fixed space. Line height is part of the core editor and does not require a plugin.

[[what-line-height-does]]
== What line height does

* Applies a line height to each selected paragraph, heading, list item, table cell, or `+div+` element.
* Stores the value as an inline `+line-height+` style on each block, so the spacing is kept when the content is displayed outside the editor.
* Removes the line height when the value already applied to the selection is chosen again.
* Offers a configurable list of values through the xref:#line_height_formats[`+line_height_formats+`] option.
* Is available from the `+lineheight+` toolbar button, the *Line height* item in the *Format* menu, and the `+LineHeight+` command.

[[basic-setup]]
== Basic setup

The *Line height* item is included in the default *Format* menu. To also show the toolbar button, add `+lineheight+` to the xref:toolbar-configuration-options.adoc#toolbar[`+toolbar+`] option.

[source,js]
----
tinymce.init({
  selector: 'textarea', // change this value according to your HTML
  toolbar: 'undo redo | blocks | bold italic | lineheight'
});
----

== 4.0.0 - 2024-12-13

=== Removed

* Removed GoogleDrive plugin due to changes in Google's API.

=== Fixed

* Fixed high level security issue with the installer.
* Fixed various PHP 8+ compatibility issues.

== 3.0.0 - 2023-05-04

=== Added

* Added support for PHP 8.2 and removed support for PHP 7.x since it's end of life.

=== Fixed

* Fixed so the file path encoding is UTF-8 for Windows instead of Windows-1252.
* Fixed issue with implicit convert from float to int in ImageAlter.

* Better sorting files by filenames. If a filename contains only digits, it will be sorted by comparing names as digits.
* Improved UX experience while using the search field and selecting found files.

=== Changed

* Allow uploading any filetypes (extensions) on iOS devices.

=== Fixed

* Fixed compatibility issues with PHP 8.

=== Added

* Added inline mode for uploads makes it way faster to upload files.

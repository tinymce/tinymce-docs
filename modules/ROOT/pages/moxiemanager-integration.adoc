= MoxieManager integration
:navtitle: Integration
:description: Integrate MoxieManager with {productname} and other systems.
:keywords: moxiemanager, integration, tinymce, wordpress

Ok, so you have tested it on your server and have made sure it works, time to integrate it with whatever system you might be using.

This is really the part that can be somewhat tricky, certain system require specific Authenticators or custom Authenticators in order to work properly. It can be especially tricky if you system has some custom managment of Sessions.

[[tinymce-integration]]
== {productname} integration

MoxieManager picks up certain xref:#tinymce-integration[config options] when integrated into {productname}.

These are setting you should *set in your {productname} configuration* in order to get the setup you want. See below for examples!

If you are using xref:moxiemanager-api.adoc[moxman.browse, check these API docs].

=== Examples

[source,js]
----
tinymce.init({
  ...
  moxiemanager_rootpath : '/files/subfolder'
});
----

The rootpath must be within the rootpath set in config.php for security reasons.

[source,php]
----
$moxieManagerConfig["filesystem.rootpath"] = "/www/site/files";
----

`+moxiemanager_rootpath : '/files/subfolder'+` is a valid config option if subfolder exists.

`+moxiemanager_rootpath : '/othersite/files'+` is NOT a valid config option.

[source,js]
----
tinymce.init({
  ...
  relative_urls : false,
});
----

MoxieManager always returns an absolute URL to {productname}, then the {productname} options convert the urls. In this case, relative_urls is set to false, when you save in {productname}, the resulting path will be:

`+/my/absolute/url.jpg+`

Since remove_script_host is false by default.

[source,js]
----
tinymce.init({
  ...
  relative_urls : false,
  remove_script_host : false
});
----

With this example, urls will be absolute WITH the site domain.

`+http://www.mysite.com/my/absolute/url.jpg+`

NOTE: Note, lets say you have `+admin.mysite.com+`, you can configure `+document_base_url : 'http://www.mysite.com'+`

Then URLs should become just as above, and not `+admin.mysite.com+` absolute.

==== Basic integration

This is how you integrate the MoxieManager into {productname}.

[source,js]
----
tinymce.init({
  selector: "textarea",
  plugins: "moxiemanager link image",
  toolbar: "insertfile link image",
  menubar: false
});
----

This is the most basic integration example.

==== Custom settings

These are some examples of custom settings that can be passed from {productname} to MoxieManager.

For more detailed info about configuration options, check out the xref:#tinymce-integration[{productname} integration] page.

[source,js]
----
tinymce.init({
  selector: "textarea",
  plugins: "moxiemanager link image",
  toolbar: "insertfile link image",
  menubar: false,
  moxiemanager_file_settings: {
    /* Only list txt files, and remove side navigation. */
    moxiemanager_extensions : 'txt',
    moxiemanager_leftpanel : false
  },
  moxiemanager_image_settings: {
    /* Scope to different folder, show thumbnails of selected extensions */
    moxiemanager_title : 'Images',
    moxiemanager_extensions : 'jpg,png,gif',
    moxiemanager_rootpath : '/testfiles/testfolder',
    moxiemanager_view : 'thumbs'
  }
});
----

==== Using with CDN version of {productname}

In order to load MoxieManager, you need to run it with as an external plugin.

[source,js]
----
tinymce.init({
  ...
  plugins: "moxiemanager link image",
  external_plugins: {
    "moxiemanager": "/moxiemanager/plugin.min.js"
  }
});
----

== Wordpress integration

These instructions should work for any Wordpress version above 2.5.

. Download the MoxieManager package from this website.
. Unzip the package so the Wordpress structure looks like this: `+/wp-includes/js/tinymce/plugins/moxiemanager+`
. Download xref:attachment$moxiemanager/mce.zip[this Wordpress plugin package] and unzip so the structure looks like this: `+/wp-content/plugins/mce+`
. Login to Wordpress as administrator, activate the MoxieManager plugin.
. Create a new post or page, the editor should now have an extra button, click it and follow the installation instructions, choose the SessionAuthenticator and leave the session name intact as isLoggedIn.
. Continue and save the config and you are done, you might have to logout/login to Wordpress again for it to work.

If you have any issues, please use the support ticket system and we will try to assist you.

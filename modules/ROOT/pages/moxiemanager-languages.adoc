[[how-to-translate]]
== How to translate

The translations for every available language are in the xref:#download-language-packs[MoxieManager language packs]. There is one special item called "_dateformatter.datetime" this is the default format string for dates and different languages have different xref:moxiemanager-options.adoc#date-format[formats]. If you need help with the translation process, link:https://support.tiny.cloud/hc/en-us/requests/new[open a support ticket].

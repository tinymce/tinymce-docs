== .NET example plugin

You can download an example plugin for .NET here, this is a Visual Studio 2012 solution, to build a custom plugin, follow these steps:

. Unpack the zip and open up the solution in Visual Studio (2012 recommended).
. Add a reference to the MoxieManager.Core.dll file before building, modify/add/remove any code you wish.
. Build and copy the resulting DLL into the same bin folder as the other DLL files for MoxieManager.
. Add the appropriate line to your Web.Config file so the plugin gets included, make note of the name so it matches yours.

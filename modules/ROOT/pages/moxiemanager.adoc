MoxieManager is a premium {productname} plugin and server system that enables users to insert files located externally to the editor (e.g. on their client desktop) into their document.

MoxieManager is an application separate from {productname} that includes .NET or PHP server components. Being built by the team behind {productname} it has tight integration with the editor via a toolbar control. It is designed to work with {productname} configuration settings such as `+relative_urls+`.

NOTE: MoxieManager is a paid addition to {productname}. It is included in link:{pricingpage}/[{enterpriseversion} subscriptions].

== Getting started

Full documentation on MoxieManager, including xref:moxiemanager-installation.adoc[installation] and how to xref:moxiemanager-integration.adoc#tinymce-integration[integrate with {productname}], is provided in the following pages.

This documentation will show you how to install, configure and customize MoxieManager to fit your needs.

If your here for the first time, we recommend these sections first.

. xref:moxiemanager-installation.adoc[Installation]
. xref:moxiemanager-integration.adoc[Integration]

The configuration can seem daunting at first, but its very powerfull, and the use of *xref:moxiemanager-how-to-guides.adoc#how-to-use-mc-access[mc_access]* files can really increase the power of configuration by a lot. Template folders also enables you to copy pre-configured folder configs (by including an mc_access file) to have a really custom experience.

Also, check out the xref:moxiemanager-how-to-guides.adoc[How-to section] for some advanced info on how to configure certain things, such as upload.format and other powerfull options.

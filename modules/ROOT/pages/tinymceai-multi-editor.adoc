Multi-editor mode groups several {productname} editors on one page, such as the sections of a form, so that they share one Chat sidebar and one Review sidebar. Chat, Review, and Quick Actions work across the content of every editor in the group.

[[how-grouped-editors-work]]
== How grouped editors work

[[shared-sidebar]]
=== Shared sidebar

The first editor of the group to be created hosts the shared Chat sidebar and Review sidebar. The Chat and Review toolbar buttons and menu items in every other editor of the group open, close, and focus that shared sidebar.

In xref:tinymceai.adoc#decoupled-mode[decoupled mode], the first editor of the group hosts AI Chat and AI Review in the element set by its xref:tinymceai.adoc#tinymceai_decoupled_container[`+tinymceai_decoupled_container+`] value. The Chat and Review toolbar buttons and menu items in every editor of the group open and close AI Chat and AI Review in that element, and the keyboard shortcuts in every editor open them.

[[chat]]
=== Chat

By default, each chat prompt includes the content of every editor in the group. Each editor appears above the prompt as a context tag labeled with its xref:tinymceai.adoc#tinymceai_document_name[`+tinymceai_document_name+`] value, for example image:tinymceai/tinymceai-context-tag.png[Body context tag] for an editor named `+Body+`.

Users can change which editors the AI works with:

* Removing a context tag leaves the content of that editor out of the prompt, and the AI does not change that editor.
* The **Add context source** menu lists every editor in the group and adds a removed editor back.

After a message is sent, the editors included in that message stay in the conversation and their context tags cannot be removed until the user starts a new conversation. Editors that were left out can still be added from the **Add context source** menu at any point in the conversation.

The AI can change the content of any editor in the conversation, and the plugin previews and applies each change in the editor it belongs to. To direct a request at the content of one editor, name that content in the prompt, for example _"Shorten the Introduction"_. For more information about chat, see xref:tinymceai-chat.adoc[Chat].

[[review]]
=== Review

A review analyzes the content of every editor in the group. The Review sidebar groups suggestions under the name of the editor they belong to and shows the number of pending suggestions in each group. A review always covers the whole group. For more information about reviews, see xref:tinymceai-review.adoc[Review].

[[quick-actions]]
=== Quick Actions

Users can run a Quick Action from any editor in the group. What the Quick Action changes depends on whether text is selected in that editor:

* With text selected, the Quick Action changes only the selected text in that editor.
* With no text selected, the Quick Action changes the whole content of every editor in the group and ignores any text selected in the other editors. For example, running **Translate** with no text selected translates every editor in the group.

Chat actions, such as **Explain**, **Summarize**, and **Highlight key points**, open the shared Chat sidebar and start a conversation that includes every editor in the group, as described in xref:#chat[Chat]. For more information about Quick Actions, see xref:tinymceai-actions.adoc[Quick Actions].

[[previewing-and-applying-changes]]
=== Previewing and applying changes

While the {pluginname} plugin previews changes from Chat or Quick Actions, each affected editor shows its own preview and is read-only. The whole group shares one change toolbar:

* The change counter covers the changes in every editor of the group.
* The next and previous buttons move between changes across editors.
* Selecting a change in any editor moves the change toolbar to that change.
* Accepting or rejecting a change applies it to the editor that holds the change.

[[discarding-suggestions]]
=== Discarding pending suggestions

With the floating sidebar, when any editor in the group has pending suggestions, the {pluginname} plugin asks for confirmation before it discards them and starts a different AI task. For example, the confirmation dialog appears when the user switches between the Chat sidebar and the Review sidebar, or runs a Quick Action while a review has pending suggestions.

If the user confirms, the plugin discards the suggestions in every editor of the group, resets the changes already applied, and returns each editor to normal editing. If the user cancels, the plugin keeps every preview and pending suggestion.

[[integration]]
== Integration

To group editors, load the `+tinymceai+` plugin in each editor and set the same xref:tinymceai.adoc#tinymceai_group[`+tinymceai_group+`] value on each editor in the group. Give each editor a unique xref:tinymceai.adoc#tinymceai_document_name[`+tinymceai_document_name+`] value, and optionally a xref:tinymceai.adoc#tinymceai_document_description[`+tinymceai_document_description+`] value that describes the content to the AI.

The floating sidebar and xref:tinymceai.adoc#decoupled-mode[decoupled mode] both support multi-editor mode. For the floating sidebar, set xref:tinymceai.adoc#tinymceai_sidebar_type[`+tinymceai_sidebar_type+`] to `+'floating'+` for every editor in the group. For decoupled mode, see xref:#decoupled-mode-group[Grouped editors in decoupled mode].

Use the same {pluginname} configuration for every editor in a group, for example by sharing a settings object between the `+tinymce.init+` calls:

[source,js]
----
const sharedSettings = {
  plugins: 'tinymceai',
  toolbar: 'tinymceai-chat tinymceai-quickactions tinymceai-review',
  tinymceai_sidebar_type: 'floating',
  tinymceai_group: 'article',
  // Required for authentication
  tinymceai_token_provider: () => {
    return fetch('/api/token').then(r => r.text()).then(token => ({ token }));
  }
};

tinymce.init({
  ...sharedSettings,
  selector: 'textarea#introduction', // change this value according to the HTML
  tinymceai_document_name: 'Introduction',
  tinymceai_document_description: 'The introduction of the article. A short paragraph that sets out the topic and hooks the reader.'
});

tinymce.init({
  ...sharedSettings,
  selector: 'textarea#body', // change this value according to the HTML
  tinymceai_document_name: 'Body',
  tinymceai_document_description: 'The main body of the article. Uses h2 subheadings and short paragraphs.'
});
----

Grouped editors must be on the same page and use the same `+tinymce+` instance. Set xref:tinymceai.adoc#tinymceai_group[`+tinymceai_group+`] in the initial configuration of each editor.

For information about installing the plugin and enabling AI features, see xref:tinymceai.adoc[Plugin Reference].

[[decoupled-mode-group]]
=== Grouped editors in decoupled mode

include::partial$misc/admon-requires-8.11v.adoc[]

To use xref:tinymceai.adoc#decoupled-mode[decoupled mode] with a group, add one element for the group to the page and set xref:tinymceai.adoc#tinymceai_decoupled_container[`+tinymceai_decoupled_container+`] to a CSS selector that matches it. The plugin uses the value set on the first editor created in the group, so the option can go in the shared settings object. To open AI Chat or AI Review when the page loads, set xref:tinymceai.adoc#tinymceai_decoupled_show[`+tinymceai_decoupled_show+`].

[source,html]
----
<div style="display: flex; gap: 16px;">
  <div style="flex: 1;">
    <textarea id="introduction"></textarea>
    <textarea id="body"></textarea>
  </div>
  <div id="ai-panel" style="width: 400px; height: 800px; box-sizing: border-box; border: 2px solid #eee; border-radius: 10px; overflow: hidden;"></div>
</div>
----

[source,js]
----
const sharedSettings = {
  plugins: 'tinymceai',
  toolbar: 'tinymceai-chat tinymceai-quickactions tinymceai-review',
  tinymceai_group: 'article',
  tinymceai_decoupled_container: '#ai-panel', // change this value according to the HTML
  tinymceai_decoupled_show: 'tinymceai-chat',
  // Required for authentication
  tinymceai_token_provider: () => {
    return fetch('/api/token').then(r => r.text()).then(token => ({ token }));
  }
};

tinymce.init({
  ...sharedSettings,
  selector: 'textarea#introduction', // change this value according to the HTML
  tinymceai_document_name: 'Introduction'
});

tinymce.init({
  ...sharedSettings,
  selector: 'textarea#body', // change this value according to the HTML
  tinymceai_document_name: 'Body'
});
----

To open or close AI Chat and AI Review programmatically, see xref:tinymceai.adoc#tinymceai-toggling-apps-decoupled[`+TinyMCEAIToggleApp+`].

[[multiple-groups]]
=== Multiple groups on one page

A page can contain several independent groups, each with a different xref:tinymceai.adoc#tinymceai_group[`+tinymceai_group+`] value. Each group has its own shared sidebar, and an editor in one group never receives the content of an editor in another group. In decoupled mode, give each group its own element and set a different xref:tinymceai.adoc#tinymceai_decoupled_container[`+tinymceai_decoupled_container+`] value for each group. For a configuration with two groups, see the xref:tinymceai.adoc#tinymceai_group[two-group example].

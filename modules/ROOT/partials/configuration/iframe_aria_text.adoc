[[iframe_aria_text]]
== `+iframe_aria_text+`

This option sets the accessible name for the {productname} `+iframe+` and its editable content area. The value is read by screen readers to help users identify the editor.

{productname} applies the value as follows:

* **All operating systems**: {productname} sets the value as the `+title+` attribute of the iframe element.
* **macOS and iOS**: {productname} also sets the value as an `+aria-label+` on the `+<body>+` element inside the iframe document, together with `+role="textbox"+` and `+aria-multiline="true"+`. The VoiceOver screen reader does not announce the iframe `+title+`, so the `+<body>+` element carries the accessible name on these operating systems.

For example, on macOS:

[source,html]
----
<iframe title="Rich Text Area">
  <!-- Inside the iframe document -->
  <body role="textbox" aria-multiline="true" aria-label="Rich Text Area"></body>
</iframe>
----

This option only applies to {productname} classic (iframe) mode and has no effect on xref:inline-editor-options.adoc#inline[`+inline+` editors].

*Type:* `+String+`

*Default value:* `+'Rich Text Area'+`

When the xref:help.adoc[Help] plugin is loaded, `+'. Press ALT-0 for help.'+` is appended to the default value, giving `+'Rich Text Area. Press ALT-0 for help.'+`. The suffix is not added when the plugin is not loaded, because the shortcut it describes is unavailable.

=== Example: using `+iframe_aria_text+`

[source,js]
----
tinymce.init({
  selector: 'textarea',  // change this value according to your HTML
  iframe_aria_text: 'Text Editor'
});
----

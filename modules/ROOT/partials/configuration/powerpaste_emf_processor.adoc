[[powerpaste_emf_processor]]
== `+powerpaste_emf_processor+`

This option controls how `emf` images are handled. If this option **is** provided, `emf` image blobs will be converted into `png` image blobs using the supplied function, which will then be pasted into the editor. If this option is **not** provided, the editor will remove the poor quality images, and show an error message.

*Type:* `+Function+`

=== Example: `+powerpaste_emf_processor+`

[source,js]
----
tinymce.init({
  selector: 'textarea',  // change this value according to your HTML
  plugins: 'powerpaste',
  powerpaste_word_import: 'clean',
  powerpaste_emf_processor: (blob) => {
	  return fetch('YOUR_IMAGE_URL').then(res => res.blob())
	}
  });
----

NOTE: When `+powerpaste_emf_processor+` is not provided, an `emf` image pastes correctly only when it is selected on its own. If the image is selected together with other content, such as text, the other content is pasted, but the image is replaced with a broken image placeholder and the editor displays the error notification "Some images failed to import." To paste `emf` images together with other content, provide a `+powerpaste_emf_processor+` function that converts the images to `png`. Alternatively, select and paste each `emf` image on its own.

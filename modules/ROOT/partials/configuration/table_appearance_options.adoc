[[table_appearance_options]]
== `+table_appearance_options+`

This option controls which appearance fields the Table Properties dialog shows when a user inserts or edits a table. The appearance fields are **Cell spacing**, **Cell padding**, **Border width**, and **Caption**. When the option is set to `+false+`, none of these fields appear. When the option is set to `+true+`, all of them appear.

To hide individual fields, set the option to an object instead. A field set to `+false+` is hidden. A field set to `+true+` or left out is shown, so an empty object shows all four fields.

NOTE: The object form of this option is only available in {productname} 8.11 and later. Earlier versions accept only `+true+` or `+false+`.

*Type:* `+Boolean+` or `+Object+`

*Default value:* `+true+`

*Possible values:* `+true+`, `+false+`, or an object with any of the following `+Boolean+` properties:

* `+cellspacing+`: the **Cell spacing** field.
* `+cellpadding+`: the **Cell padding** field.
* `+borderwidth+`: the **Border width** field.
* `+caption+`: the **Caption** field.

If any of these properties has a value that is not a `+Boolean+`, {productname} logs a warning to the browser console and ignores the whole object. All four fields then appear, as with the default value `+true+`. Properties other than these four have no effect.

=== Example: using `+table_appearance_options+`

[source,js]
----
tinymce.init({
  selector: 'textarea',  // change this value according to your HTML
  plugins: 'table',
  toolbar: 'table',
  table_appearance_options: false
});
----

=== Example: hiding individual fields

[source,js]
----
tinymce.init({
  selector: 'textarea',  // change this value according to your HTML
  plugins: 'table',
  toolbar: 'table',
  table_appearance_options: {
    cellspacing: false,
    caption: false
  }
});
----

      <li>Place the insertion point on the empty line under <strong>Follow-up</strong> and select <span class="demo-ui">Insert template</span> in the toolbar.</li>
      <li>Expand <strong>With an insertion point marker</strong>, select <strong>Follow-up email</strong>, and select <span class="demo-ui">Insert</span>. The insertion point lands on the empty line after the greeting, so the message can be typed straight away.</li>
      <li>Insert <strong>Follow-up email</strong> from <strong>Without an insertion point marker</strong>. This time the insertion point lands at the end of the inserted content.</li>
      <li>Compare the two <strong>Meeting notes</strong> templates. With the marker, typing starts in the <strong>Attendees</strong> cell. In both versions the date, prospect, and sales rep placeholders become merge tags, and the marker does not.</li>

      <li>Select the paragraph under <strong>Policy wording</strong>, then open <span class="demo-ui">AI shortcuts</span> in the toolbar and choose <span class="demo-ui">Rewrite in plain language</span>. The <span class="demo-ui">AI Assistant</span> dialog opens and writes a response.</li>

      <li>Place the insertion point in the empty paragraph at the end of the guide and open <span class="demo-ui">AI shortcuts</span> again.       <li>Select <span class="demo-ui">Ask AI</span> in the toolbar, or press <kbd>Ctrl</kbd>+<kbd>J</kbd> (<kbd>⌘</kbd>+<kbd>J</kbd> on macOS), to type a request of any kind, such as <code>Add a sentence about frozen pipes</code>, then select <span class="demo-ui">Generate</span>.</li>
    </ol>
  </div>

    <summary class="demo-guide__label">Configured in this demo</summary>

      <li><code>ai_shortcuts</code> replaces the default shortcuts with five insurance shortcuts, including a nested <strong>Change tone</strong> menu. Shortcuts with <code>selection: true</code> need selected text, and the claim acknowledgment, with <code>selection: false</code>, needs an empty selection.</li>
    </ul>

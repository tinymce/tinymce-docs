    <span class="demo-guide__title">Autocompleter</span>

  <div class="demo-guide__body">
    <p class="demo-guide__task">The Thursday draft in this social media queue still needs the farm&#8217;s handle and a hashtag. Insert the <code>@</code> and <code>#</code> signs with an autocompleter that opens when a word starts with a colon.</p>
    <ol class="demo-guide__steps">
      <li>Place the insertion point at the end of the draft post that starts <strong>Fresh from the oven</strong> and type a space.</li>
      <li>Type <code>:at</code>. The menu shows two characters, <strong>!</strong> and <strong>@</strong>, because the search matches anywhere in each character&#8217;s name, and &#8220;exclamation mark&#8221; also contains &#8220;at&#8221;. Select <strong>@</strong>, then type <code>MillLaneFarm</code>.</li>
      <li>Type a space and <code>:hash</code>. The menu narrows to <strong>#</strong>. Press <kbd>Enter</kbd> to insert it, then type <code>HarborStreetBakes</code>.</li>
      <li>Type <code>:a</code> and press <kbd>Esc</kbd>. The menu closes and the typed text stays as it is.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>editor.ui.registry.addAutocompleter</code> registers the <code>specialchars</code> autocompleter with <code>trigger: ':'</code> and <code>minChars: 1</code>, so the menu opens after a colon at the start of a word plus one more character.</li>
      <li><code>fetch</code> returns <code>autocompleteitem</code> entries for every character whose name contains the typed text, using the character as the icon.</li>
      <li><code>columns: 'auto'</code> lays the matches out as a grid of characters.</li>
      <li><code>onAction</code> replaces the typed text, colon included, with the chosen character.</li>
      <li>The Character Map plugin is not loaded, because it registers its own <code>:</code> autocompleter, which would add its characters to this menu.</li>
    </ul>
  </details>
</div>

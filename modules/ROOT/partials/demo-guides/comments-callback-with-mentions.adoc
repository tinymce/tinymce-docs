  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>tinycomments_mentions_enabled: true</code> turns on mentions in comments. A mention is saved in the comment text as <code>@</code> followed by the user ID.</li>
      <li><code>mentions_fetch</code> searches a demo user directory for the text typed after <code>@</code>, and <code>mentions_min_chars: 0</code> shows the list as soon as <code>@</code> is typed.</li>
      <li><code>mentions_item_type: 'profile'</code> shows a photo and a role for each person in the list.</li>
      <li><code>mentions_menu_complete</code> inserts each mention into the document as a <code>mymention</code> span, and <code>mentions_selector: '.mymention'</code> identifies those spans as mentions.</li>
      <li><code>mentions_menu_hover</code> and <code>mentions_select</code> return the profile cards shown in the list and when pointing to a mention in the document.</li>
      <li><code>content_style</code> and the CSS tab color mentions in the document and in the sidebar.</li>
      <li><code>tinycomments_mode: 'callback'</code> with the <code>tinycomments_create</code>, <code>tinycomments_reply</code>, <code>tinycomments_edit_comment</code>, <code>tinycomments_delete_comment</code>, <code>tinycomments_delete</code>, <code>tinycomments_resolve</code>, <code>tinycomments_delete_all</code>, <code>tinycomments_lookup</code> and <code>tinycomments_fetch</code> callbacks saves conversations to a simulated server and lets only the author of a comment, or the person who started a conversation, change it.</li>
      <li><code>tinycomments_always_show_highlights: true</code>, <code>sidebar_show: 'showcomments'</code>, <code>user_id</code> and <code>fetch_users</code> keep highlights visible, open the sidebar on load, and sign in James Wilson.</li>
      <li><code>quickbars_selection_toolbar</code> adds <span class="demo-ui">Add comment</span> to the toolbar over selected text.</li>
    </ul>
  </details>

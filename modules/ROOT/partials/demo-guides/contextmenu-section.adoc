  <div class="demo-guide__body">
    <p class="demo-guide__task">This roadmap note has one photo. A small custom plugin adds an <span class="demo-ui">Image</span> item to the context menu, but only when an image is right-clicked.</p>
    <ol class="demo-guide__steps">
      <li>Right-click the laptop photo under <strong>Prototype from the design sprint</strong>. The context menu shows one item, <span class="demo-ui">Image</span>.</li>
      <li>Select <span class="demo-ui">Image</span>. The item&#8217;s action opens a browser alert that reads <strong>context menu clicked</strong>. Select <span class="demo-ui">OK</span> to close it.</li>
      <li>Right-click any paragraph. The section has no items for text, so the browser&#8217;s own context menu opens instead.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>tinymce.PluginManager.add</code> registers <code>my-example-plugin</code>, which adds the <code>image</code> menu item with <code>editor.ui.registry.addMenuItem</code>.</li>
      <li><code>editor.ui.registry.addContextMenu('image')</code> returns the <code>image</code> item only when the right-clicked element has a <code>src</code>, and an empty string otherwise.</li>
      <li><code>contextmenu: 'image'</code> shows only this section.</li>
      <li>The Image plugin is not loaded, because it registers a menu item and a context menu section with the same <code>image</code> name, which would replace the ones from the example plugin.</li>
    </ul>
  </details>
</div>

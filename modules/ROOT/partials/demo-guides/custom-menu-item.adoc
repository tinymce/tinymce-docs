    <ol class="demo-guide__steps">
      <li>Click at the end of the answer that starts with <strong>Most installations</strong>, then select <span class="demo-ui">Custom menu</span> &gt; <span class="demo-ui">My basic menu item</span>. A paragraph is inserted below the answer.</li>
      <li>Open <span class="demo-ui">Custom menu</span> &gt; <span class="demo-ui">My nested menu item</span> and select <span class="demo-ui">My submenu item</span>.</li>
      <li>Select <span class="demo-ui">Custom menu</span> &gt; <span class="demo-ui">My toggle menu item</span>. Open <span class="demo-ui">Custom menu</span> again: the item now shows a check mark, and selecting it again clears the check mark.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>menu: { custom: { title: 'Custom menu', items: 'basicitem nesteditem toggleitem' } }</code> defines the new menu and its items.</li>
      <li><code>menubar: 'file edit view insert format tools table custom help'</code> adds <strong>Custom menu</strong> to the default menus.</li>
      <li><code>editor.ui.registry.addMenuItem</code>, <code>addNestedMenuItem</code> and <code>addToggleMenuItem</code> register the three items.</li>
    </ul>

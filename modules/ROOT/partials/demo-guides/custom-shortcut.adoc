      <li>In the second paragraph under <strong>Matter summary</strong>, select <strong>October 31</strong> in the sentence about the lease.</li>
      <li>Press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Y</kbd> (<kbd>⌘</kbd>+<kbd>Option</kbd>+<kbd>Y</kbd> on macOS). The selected text gets a yellow highlight.</li>

      <li>To remove a highlight, select the text, open the arrow next to <span class="demo-ui">Background color</span> in the toolbar and choose <span class="demo-ui">Remove color</span>.</li>

    <ul class="demo-guide__options">
      <li><code>editor.addShortcut('meta+alt+y', …)</code> registers the shortcut. <code>meta</code> is <kbd>Ctrl</kbd> on Windows and Linux and <kbd>⌘</kbd> on macOS.</li>
      <li>The shortcut runs the <code>hilitecolor</code> command with <code>#FFFF00</code>, which applies a yellow background color to the selection.</li>

      <li>Select the two paragraphs that start with <strong>Thank you for your letter</strong> and <strong>We have issued credit note</strong>, then select <span class="demo-ui">Alignment</span> &gt; <span class="demo-ui">Justify</span>.</li>

    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>editor.ui.registry.addGroupToolbarButton</code> adds <strong>Alignment</strong>, which collects the four alignment buttons in one floating toolbar. The separate alignment buttons are left out of the toolbar.</li>
      <li><code>toolbar_mode: 'floating'</code> sets the toolbar mode that group toolbar buttons require. It is also the default toolbar mode on desktop browsers.</li>

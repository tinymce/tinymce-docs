<div class="demo-guide demo-guide--premium" role="note" aria-label="Try it: Tiny Drive with Google Drive">
  <div class="demo-guide__head">
    <span class="demo-guide__eyebrow">Try it</span>
    <span class="demo-guide__title">Tiny Drive with Google Drive</span>
    <span class="demo-guide__tier">Premium plugin</span>
  </div>
  <div class="demo-guide__body">
    <p class="demo-guide__task">The 3 files under <strong>Slides and materials</strong> in this speaker packet are kept in Google Drive. Import them into the {cloudfilemanager} library and link them from the packet.</p>
    <ol class="demo-guide__steps">
      <li>Place the insertion point at the end of <strong>Summit slide template (16:9)</strong> and select <span class="demo-ui">Insert file</span> in the toolbar.</li>
      <li>In the file manager, select <span class="demo-ui">Upload/Create</span>. The menu lists <span class="demo-ui">Upload file</span>, <span class="demo-ui">Google Drive</span> and <span class="demo-ui">Create folder</span>.</li>
      <li>Select <span class="demo-ui">Google Drive</span>, sign in with a Google account when prompted, and select one or more files in the Google Drive picker. The chosen files are copied into the {cloudfilemanager} library.</li>
      <li>Select the name of an imported file to insert it. Documents are inserted as links, and images, such as a new speaker headshot, are inserted as images.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>tinydrive_google_drive_key</code> and <code>tinydrive_google_drive_client_id</code> connect {cloudfilemanager} to a Google Cloud project and add <strong>Google Drive</strong> to the <strong>Upload/Create</strong> menu.</li>
      <li>The <code>insertfile</code> toolbar button opens the file manager.</li>
      <li><code>tinydrive_token_provider</code> supplies the JSON Web Token that authorizes each request. In this demo it returns a fixed token and the file manager opens a sample library instead of a real {cloudfilemanager} account.</li>
      <li>The <code>editimage</code> plugin adds <strong>Rotate</strong>, <strong>Flip</strong>, <strong>Edit image</strong> and <strong>Image options</strong> buttons to the toolbar that appears when an image is selected.</li>
    </ul>
  </details>
</div>

    <p class="demo-guide__task">This recipe post has no photo yet. Add the moka pot photo from the file library with a picker that only offers images.</p>
    <ol class="demo-guide__steps">
      <li>Place the insertion point at the end of the introduction paragraph, above <strong>Ingredients</strong>.</li>
      <li>Select <span class="demo-ui">Custom pick image</span> in the toolbar. The top level of the library shows 2 folders and 4 images. The 2 PDF files are hidden.</li>
      <li>Open the <strong>logos</strong> folder: only the 2 PNG files appear, and the SVG and EPS files are hidden. Select <span class="demo-ui">Move one folder up</span>.</li>
      <li>Open <strong>Hero Backgrounds</strong> and select the name <strong>aluminium-antique-coffee-6255.jpg</strong>. The demo's code inserts it as an image at the insertion point.</li>
      <li>Select <span class="demo-ui">Insert file</span> to compare: without a file type filter, the same library also lists the PDF files.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>editor.ui.registry.addButton</code> in <code>setup</code> adds the <strong>Custom pick image</strong> button. It calls <code>tinydrive.pick({ filetypes: ['image'] })</code> and inserts an image for each picked file.</li>
      <li><code>filetypes: ['image']</code> limits the file manager to folders and image files.</li>
      <li><code>tinydrive_token_provider</code> supplies the JSON Web Token that authorizes each request. In this demo it returns a fixed token and the file manager opens a sample library instead of a real {cloudfilemanager} account.</li>
    </ul>
  </details>

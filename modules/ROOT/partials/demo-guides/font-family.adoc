    <p class="demo-guide__task">In this fall lookbook, look names are set in Georgia and style codes in Courier New. Look 3 breaks both rules: its name is in Trebuchet MS, and its style code <strong>CL-2063</strong> uses the body font. Fix both.</p>
    <ol class="demo-guide__steps">
      <li>Place the insertion point in any line. The font dropdown in the toolbar shows its typeface: <span class="demo-ui">Inter</span> in the introduction, <span class="demo-ui">Palatino</span> in the quote, <span class="demo-ui">Trebuchet MS</span> in the Look 3 name.</li>
      <li>Select <strong>Look 3: Evening in town</strong>, open the font dropdown and choose <span class="demo-ui">Georgia</span>.</li>
      <li>Select <strong>CL-2063</strong> in the Look 3 description and open <span class="demo-ui">Format</span> &gt; <span class="demo-ui">Fonts</span> &gt; <span class="demo-ui">Courier New</span>.</li>
      <li>Select a whole line that mixes typefaces, such as the Look 1 description, and choose one font to replace every typeface in it. Open <span class="demo-ui">Format</span> &gt; <span class="demo-ui">Clear formatting</span> to return the text to Inter.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>font_family_formats</code> replaces the default list with six fonts, each shown in its own typeface. Inter matches the body text, so plain text shows <strong>Inter</strong> instead of a font stack.</li>
    </ul>
  </details>

    <p class="demo-guide__task">This lease review memo has 5 footnotes. Add a citation, jump between a footnote number and its note, and clean up a note that is left behind when a table row is deleted.</p>
    <ol class="demo-guide__steps">
      <li>Place the insertion point at the end of the second requested change, after <strong>10 business days.</strong>, and select <span class="demo-ui">Insert footnote</span> in the toolbar. The new footnote becomes number 5, the sublease note becomes number 6, and the insertion point moves to the new note so it can be typed.</li>
      <li>Press <kbd>Ctrl</kbd> (<kbd>⌘</kbd> on macOS) and select a footnote number to jump to its note, then select the caret (<strong>^</strong>) before the note to return.</li>
      <li>Place the insertion point in the <strong>Year 5</strong> table row and open <span class="demo-ui">Table</span> &gt; <span class="demo-ui">Row</span> &gt; <span class="demo-ui">Delete row</span>. The row's note stays at the end of the memo, so select <span class="demo-ui">Update footnotes</span> in the toolbar to remove it and renumber the rest.</li>
    </ol>
  </div>

  <div class="demo-guide__head">
    <span class="demo-guide__eyebrow">Try it</span>
    <span class="demo-guide__title">Reusable template</span>
    <span class="demo-guide__tier">Editor setup</span>
  </div>
  <div class="demo-guide__body">
    <p class="demo-guide__task">This farmers market vendor agreement is a template. Only the four outlined areas can be edited, and seven merge tags mark the details that change for each vendor. Personalize it, then reset it.</p>
    <ol class="demo-guide__steps">
      <li>Point to each page. The four editable areas show an outline. The logo, the footer line, and the page backgrounds cannot be edited.</li>
      <li>Place the insertion point after "Stall fee: $35 per market day, invoiced monthly." and select <span class="demo-ui">Insert merge tag</span> &gt; <span class="demo-ui">Dates</span> &gt; <span class="demo-ui">Opening day</span>.</li>
      <li>Type <code>*{</code> followed by <code>bus</code> in an editable area, then pick <strong>Business name</strong> from the list.</li>
      <li>Open <span class="demo-ui">File</span> &gt; <span class="demo-ui">New document</span>. The editor reloads the template instead of an empty page.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>editable_root: false</code> makes the whole document read-only, and <code>editable_class: 'editable'</code> makes the areas with that class editable.</li>
      <li><code>newdocument_content</code> sets the content that <strong>New document</strong> loads.</li>
      <li><code>mergetags_prefix: '*{'</code> and <code>mergetags_suffix: '}*'</code> set the merge tag delimiters, and <code>mergetags_list</code> sets the Vendor and Dates categories.</li>
      <li><code>content_style</code> lays out the pages, backgrounds, and outlines of the template.</li>
      <li><code>elementpath: false</code> hides the element path in the status bar.</li>
      <li>The <code>advcode</code> plugin replaces <code>code</code>.</li>
    </ul>
  </details>
</div>

  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>inline: true</code> edits the headings and sections in place, styled by the page stylesheet.</li>
      <li><code>menubar: false</code> hides the menu bar for both editor types.</li>
      <li><code>valid_elements</code> limits the headings to bold, italic, styled text, and links, and the body sections to paragraphs, lists, and the same inline formats.</li>
      <li><code>valid_styles</code> keeps only font size, font family, color, text decoration, and alignment styles.</li>
      <li><code>powerpaste_word_import: 'clean'</code> and <code>powerpaste_html_import: 'clean'</code> strip formatting from pasted content.</li>
      <li>The body editors load the <code>tinymcespellchecker</code> plugin for as-you-type spell checking.</li>
    </ul>

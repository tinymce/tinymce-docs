    <p class="demo-guide__task">This renewal email is a template. Each merge tag is a placeholder that the sending application replaces with one customer's details. Edit the template the way a marketing or billing team would.</p>
    <ol class="demo-guide__steps">
      <li>Select <span class="demo-ui">Insert merge tag</span> in the toolbar, or open <span class="demo-ui">Insert</span> &gt; <span class="demo-ui">Merge tag</span>, then open <span class="demo-ui">Customer</span> &gt; <span class="demo-ui">Billing address</span> to browse a nested category.</li>
      <li>Type <code>{*</code> anywhere in the text, followed by part of a name such as <code>seat</code>, then pick a tag from the list that appears.</li>
      <li>Select an existing tag, such as the plan name in the subject line, then pick a different tag from <span class="demo-ui">Insert merge tag</span> to replace it.</li>
      <li>Type in the <span class="demo-ui">Filter merge tags</span> box at the top of the menu to search every category at once.</li>
      <li>Select a tag and apply <span class="demo-ui">Bold</span> or a <span class="demo-ui">Text color</span>. Tags cannot be edited as text, but they take inline formatting, like the bold, blue amount due.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>mergetags_prefix</code> and <code>mergetags_suffix</code> replace the default braces with <code>{*</code> and <code>*}</code>.</li>
      <li><code>mergetags_list</code> defines four categories, a nested address submenu and one tag outside any category.</li>
      <li><code>content_style</code> restyles the tags through their <code>mce-mergetag</code> classes.</li>
    </ul>
  </details>

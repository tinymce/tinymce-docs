    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>skin: 'fabric'</code> styles the menu bar, toolbar, menus and dialogs in the Microsoft Fabric design language. The skin has no outer border, so the blue header bar and the gray border around the editor come from the demo page CSS.</li>
      <li><code>content_css: 'fabric'</code> loads the matching content styles, which show the text as a white page on a gray background.</li>
      <li><code>toolbar_mode: 'floating'</code> moves toolbar buttons that do not fit on narrow screens into a drawer, opened with <span class="demo-ui">Reveal or hide additional toolbar items</span>.</li>

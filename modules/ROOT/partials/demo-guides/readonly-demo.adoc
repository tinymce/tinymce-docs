    <p class="demo-guide__task">This published security policy opens in read-only mode. Confirm that it cannot be changed, then switch to editing and move the next review date to December 1, 2027.</p>
    <ol class="demo-guide__steps">
      <li>Click in the policy text. The insertion point can be placed and text can be selected and copied, but typing does not change the content. Formatting buttons such as <span class="demo-ui">Bold</span> and <span class="demo-ui">Italic</span> are unavailable.</li>
      <li>Open <span class="demo-ui">View</span> &gt; <span class="demo-ui">Preview</span>, or open <span class="demo-ui">Help</span> &gt; <span class="demo-ui">Help</span>. Both still work in read-only mode.</li>
      <li>Select <span class="demo-ui">Edit policy</span> in the toolbar. The button shows as pressed, the editor switches to design mode, and the formatting buttons become available.</li>
      <li>Change the next review date, then select <span class="demo-ui">Edit policy</span> again to return to read-only mode.</li>
    </ol>
  </div>
  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>readonly: true</code> starts the editor in read-only mode.</li>
      <li><code>editor.ui.registry.addToggleButton</code> adds the <strong>Edit policy</strong> button. <code>context: 'any'</code> keeps it available in read-only mode, and the button calls <code>editor.mode.set()</code> to switch between <code>'readonly'</code> and <code>'design'</code>.</li>
    </ul>
  </details>

      <li>Place the insertion point at the end of the paragraph under <strong>Mascot vote results</strong> and select the <span class="demo-ui">{;}</span> button, the first button in the toolbar.</li>
      <li>The <strong>Redial Demo</strong> dialog opens with <span class="demo-ui">Previous</span> and <span class="demo-ui">Next</span> both disabled. Check <span class="demo-ui">I agree to disagree</span> to enable <span class="demo-ui">Next</span>.</li>

    </ol>

  <details class="demo-guide__config">
    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>page1Config</code> starts with both footer buttons disabled. Its <code>onChange</code> callback calls <code>dialogApi.setEnabled('uniquename', data.anyterms)</code> to follow the checkbox.</li>
      <li>Its <code>onAction</code> callback calls <code>dialogApi.redial(page2Config)</code> when <span class="demo-ui">Next</span> is selected.</li>
      <li><code>page2Config</code> adds a <code>selectbox</code> whose items have the values <code>meow</code>, <code>woof</code>, and <code>thunk</code>. Its <code>onAction</code> inserts the chosen value and calls <code>dialogApi.close()</code>.</li>
      <li><code>editor.ui.registry.addButton('wizardExample')</code> adds the toolbar button, which opens the first page.</li>
    </ul>
  </details>

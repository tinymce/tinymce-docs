      <li>The <span class="demo-ui">AI Review</span> sidebar is open and lists six reviews, from <span class="demo-ui">Proofread</span> to <span class="demo-ui">Custom review</span>. Select <span class="demo-ui">Improve readability</span>, then <span class="demo-ui">Run</span>.</li>

      <li>Select <span class="demo-ui">Complete</span>, then <span class="demo-ui">Complete review</span> to keep the applied changes and make the article editable again.       <li>Select <span class="demo-ui">Adjust tone and style</span>, choose one of the five tones, such as <span class="demo-ui">Professional</span>, and select <span class="demo-ui">Run</span>.</li>

      <li><code>tinymceai_languages</code> sets the 12 languages in the <strong>Translate</strong> toolbar menu.</li>
      <li><code>tinymceai_quickactions_custom</code> adds a <strong>Challenge</strong> chat prompt under <strong>AI Quick Actions</strong> &gt; <strong>Other</strong>.</li>
      <li><code>quickbars_selection_toolbar: 'tinymceai-quickactions addcomment'</code> shows <strong>AI Quick Actions</strong> and <strong>Add comment</strong> above selected text.</li>
      <li><code>tinymceai_chat_fetch_sources</code> and <code>tinymceai_chat_fetch_source</code> add three web pages to <strong>Add context source</strong> in Chat.</li>
      <li><code>tinymceai_token_provider</code> fetches a JSON Web Token (JWT) from a demo session before each AI request. The <strong>JS</strong> tab shows a placeholder endpoint instead.</li>
      <li>The other premium plugins (comments, mentions, revision history, suggested edits, spell checking and Uploadcare) use demo settings so the full editor works alongside {pluginname}.</li>

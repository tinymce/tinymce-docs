      <li>Click the empty <strong>Due</strong> cell for Nora Lindqvist. Open the arrow next to the second <span class="demo-ui">Insert Date</span> button and select <span class="demo-ui">Insert GMT Date</span> or <span class="demo-ui">Insert ISO Date</span>.</li>

    <summary class="demo-guide__label">Configured in this demo</summary>
    <ul class="demo-guide__options">
      <li><code>editor.ui.registry.addButton</code> adds <strong>Insert Date</strong>, a text button, and a clock icon button that <code>onSetup</code> disables inside a <code>time</code> element.</li>
      <li><code>editor.ui.registry.addToggleButton</code> adds a second clock icon button that is highlighted inside a <code>time</code> element.</li>
      <li><code>editor.ui.registry.addSplitButton</code> adds an <strong>Insert Date</strong> split button with three date formats in its menu.</li>
      <li><code>editor.ui.registry.addMenuButton</code> adds <strong>Date</strong>, with an <strong>Other formats</strong> submenu.</li>
    </ul>

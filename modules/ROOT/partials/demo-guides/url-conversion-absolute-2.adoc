      <li>Select <span class="demo-ui">Source code</span> in the toolbar, or open <span class="demo-ui">View</span> &gt; <span class="demo-ui">Source code</span>. The link written as <code>../migration-tracker/</code> is saved as <code>https://www.tiny.cloud/docs/tinymce/latest/migration-tracker/</code>, and <code>redirect-map/</code> is saved as <code>https://www.tiny.cloud/docs/tinymce/latest/url-handling/redirect-map/</code>.</li>
      <li>Find the vendor site link. It already has a full address, so it stays as written. Select <span class="demo-ui">Cancel</span>.</li>
      <li>Select a word, select <span class="demo-ui">Insert/edit link</span>, enter <code>../link/</code> as the <span class="demo-ui">URL</span>, and select <span class="demo-ui">Save</span>.</li>
      <li>Open <span class="demo-ui">Source code</span> again. The new link is saved as <code>https://www.tiny.cloud/docs/tinymce/latest/link/</code>.</li>
    </ol>

      <li><code>remove_script_host: false</code> keeps the protocol and host name of <code>document_base_url</code> in each converted address.</li>
    </ul>

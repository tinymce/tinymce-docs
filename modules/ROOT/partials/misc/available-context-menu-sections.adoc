[[available-context-menu-sections]]
== Available context menu sections

The following table shows all context menu sections, including sections provided by plugins. Any menu item can also be added to the context menu. To retrieve a list from the editor, run the following command from the browser console:

[source,js]
----
tinymce.activeEditor.ui.registry.getAll().contextMenus
----

The identifier below will add a context menu _section_ containing one or more items. It is not possible to add individual items from the following context menu sections.

Each section only shows its items when the context menu is opened on matching content, as described in the *Appears when* column. A section with no matching content shows no items.

[cols="1,1,2,2",options="header"]
|===
|identifier |Core/Plugin |Appears when |Description
|advtemplate |xref:advanced-templates.adoc[Templates] |The context menu is opened anywhere in the editor. |Adds the _Save as template..._ item for saving the selected content as a template.
|configurepermanentpen |xref:permanentpen.adoc[Permanent Pen] |The permanent pen is in use. |Adds the _Permanent pen properties..._ item for opening the *Permanent Pen Properties* dialog.
|editimage |xref:editimage.adoc[Image Editing] |The context menu is opened on an editable image. |Adds the _Edit image_ item for opening the *Edit Image* dialog.
|image |xref:image.adoc[Image] |The context menu is opened on an existing, editable image. |Adds the _Image..._ item for opening the *Insert/Edit Image* dialog to edit the selected image. This section does not add an item for inserting a new image. To insert an image, use the `+image+` toolbar button or the `+image+` menu item in the *Insert* menu.
|link |xref:link.adoc[Link] |The context menu is opened on editable content. |Adds the _Link..._ item for opening the *Insert/Edit Link* dialog. When the context menu is opened on a link, the _Remove link_ and _Open link_ items are also added.
|linkchecker |xref:linkchecker.adoc[Link Checker] |The context menu is opened on a link marked as broken. |Adds the _Ignore_ item, allowing the user to instruct linkchecker to ignore the link.
|lists |xref:lists.adoc[Lists] |The context menu is opened in an ordered (numbered) list. |Adds the _List properties..._ item for opening the *List Properties* dialog.
|math |xref:math.adoc[Math] |The context menu is opened on a math equation. |Adds the _Math..._ item for editing the equation.
|spellchecker |xref:introduction-to-tiny-spellchecker.adoc[Spell Checker] |The context menu is opened on a misspelled word. |Adds a list of suggested corrections, an _Ignore_ item, and an _Ignore all_ item.
|table |xref:table.adoc[Table] |The context menu is opened in a table. |Adds table related context menu items, including Enhanced Tables context menu items (if the Enhanced Tables plugin is enabled). In a table caption, only the table properties and delete table items are added.
|===

For a list of available menu items that can be added to the context menu, see: xref:available-menu-items.adoc[Menu Items Available for {productname}].

// One-sentence summaries of core features.
// Each summary is included by its feature page and by the core features index,
// so both stay in step. Edit a summary here only.

// tag::line-height[]
Line height sets the spacing between lines of text in paragraphs, headings, list items, and table cells.
// end::line-height[]

// tag::image-upload[]
Image upload sends local images in the editor, such as pasted or dropped images, to a server and replaces each image source with the URL that the server returns.
// end::image-upload[]

// tag::font-family[]
Font family sets the typeface of selected text from a configurable list of fonts.
// end::font-family[]

// tag::font-size[]
Font size sets the size of selected text, either from a configurable list of sizes or by typing a value.
// end::font-size[]

// tag::text-color[]
Text and background color apply a color from a configurable palette, or a custom color, to selected text or to the background behind it.
// end::text-color[]

// tag::block-formats-and-styles[]
Block formats and styles apply block types, such as headings and paragraphs, and named styles defined in the editor configuration to content from dropdown menus.
// end::block-formats-and-styles[]
